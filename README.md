# URL·UTM 점검 도구 — 시연판

- **가짜 데이터 시연판**입니다. 키워드·광고그룹·기획전명·상품 코드·URL 등은 모두 가짜 값이며, 실제 광고 데이터는 들어 있지 않습니다.
- 화면: URL 점검 · UTM 점검 · 변경 대기 · 빌더(시트형) · 참조데이터
- 빌더(시트형)의 서버 기능(세팅 시트 불러오기 · 확정 · 고치기 · 취소)은 브라우저 안의 '가짜 서버'로 동작합니다. 누른 결과는 보는 사람 브라우저에만 저장되고, 헤더의 [시연 초기화]로 처음 상태로 돌아갑니다.
- 네이버 '반영'은 시연판에서도 실제로 보내지 않습니다.
